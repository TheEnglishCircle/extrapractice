How to play
  1. Team Mode: edit the names and choose any available square. Mark Correct to claim it. Mark Incorrect to pass the turn: the square stays available, so the other team can choose it.
  2. Four squares in a row, column, or diagonal wins. The first winner stays recorded, and you can keep playing through the remaining questions.
  3. Completed squares can be opened for review. Undo reverses the latest marking decision.
  4. Solo Mode: use Start / Next for questions 1–16. Answer first, reveal the model answer, then choose Got it or Needs practice. This is a self-check activity. You can also select any square.
  5. Each mode keeps its own progress while the page is open. New game resets only the current mode.

Start a new game?

This clears progress in the current mode. Team names stay the same.
